# High-resolution pin crops

Generated by `scripts/gen-pin-crops-hires.mjs` from the camera originals in
`docs/`, which are gitignored and live on Kevin's machine only.

Only poses whose shape survives a portrait crop are here — the full-bleed hook
and the arch in split. Everything else uses `public/poses/pin/`, where 1400px
is already more than a wide window needs.

Re-run with `--write` after replacing a pose photo.
