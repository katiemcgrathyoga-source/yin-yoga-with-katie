Ten minutes of easy, dynamic movement before you run — the kind that wakes a body up rather than lengthening it out.

That distinction matters more than most runners are told. Long, deep holds right before a run can leave you feeling loose and a little less powerful, which is the last thing you want on the first mile. So this one moves. Save the long holds for afterwards.
